Uji dulu minimal beberapa minggu di akun demo. Tidak ada strategi yang menjamin profit — mulai dari risiko kecil (0.5–1% per sinyal).
Preset
Preset hanya mengisi formulir — tekan Simpan pengaturan di bawah untuk menerapkan.
Market
Akhiran broker (mis. XAUUSDm di Exness) dicocokkan otomatis. Banyak pair → pakai timeframe M5 atau lebih supaya pemindaian sempat selesai.
Risiko
Mode % : lot dihitung otomatis supaya total kerugian semua posisi saat kena SL ≈ % balance yang diatur.
Stop loss / Take profit (kelipatan ATR)
Layering
Contoh: jarak 0.5 → tiap harga melawan 0.5 ATR dari layer terakhir, bot buka layer baru. Pengali 1.0 = lot sama; 1.5 = lot naik 50% tiap layer (lebih cepat TP, tapi rugi jauh lebih besar bila SL kena). SL semua layer ditaruh di luar layer terakhir.

Koneksi MetaApi
Cara dapat: daftar di app.metaapi.cloud → Accounts → Add account (isi login, password, server MT5) → salin Account ID. Token ada di menu API access.
